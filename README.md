## Deploy to GitHub Pages

The repository includes a GitHub Actions workflow that builds and deploys a static export whenever you push to `main` or `master`.

1. Push this project to a GitHub repository.
2. In the repository, open **Settings → Pages** and set **Source** to **GitHub Actions**.
3. Push to `main` or `master`, or start the **Deploy to GitHub Pages** workflow from the **Actions** tab.
4. After the workflow succeeds, open the Pages URL shown in the workflow run or under **Settings → Pages**.

The build automatically sets the repository subpath for project sites. For a user or organization site whose repository is named `<owner>.github.io`, it uses the root path.

GitHub Pages serves static files; it does not run a Next.js server or backend. Workflow edits and theme preference are stored in the current browser's local storage, so they are not shared across browsers or tenants. Shared accounts, database persistence, and server-side integrations require a separate backend.
